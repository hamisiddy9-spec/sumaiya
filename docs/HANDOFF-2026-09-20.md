## Gotchas learned (see skill `supabase-vercel-database-wiring`)

- **`browser_exec` is dead on this machine** — 420s timeouts, twice. Never a third attempt.
- **Node/native tools cannot read MSYS `/tmp`** — use `$LOCALAPPDATA/Temp`.
- **`sed -i` on a line without a trailing newline glues the next line onto it.** Rewrite env files whole; verify by printing key names only.
- **Supabase region is discoverable without credentials:** a wrong region says *"tenant not found"*, the right one *"password authentication failed"*.
- **A Vercel `repoId` goes stale when a GitHub repo is recreated** — read `link.repoId`, never reuse an old value.
- **New Vercel projects default to Deployment Protection ON** (serves a login page, not the app).
- **Android App Links need the claimed host to serve `assetlinks.json` with no redirect** — the apex 308ing to www breaks verification silently.
- **Never `git add -A`** — another writer leaves uncommitted files in this tree.
