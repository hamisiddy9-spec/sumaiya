## What changed tonight

**The AI is live.** `/api/ai/status` reports `configured:true, provider:deepseek`. A real
turn returned Swahili in 1.79s, first person ("Niambie kwanza — unafanya kazi gani…").
Before tonight it answered `"AI is not configured."`

**Every lie I could find is deleted.**
- The eight **invented job listings** served publicly from a dead endpoint → the route
  is gone; `/api/jobs/feed` now returns **404** (verified live).
- `vichujio vya waajiri` → **`vigezo`**, in all seven places, including the lint rule that
  was recommending the rejected word. The one place the word correctly means UI filters
  ("Ondoa vichujio") is untouched. Verified live: **`/sw/about` vichujio=0, vigezo=2**
  (it was 2/0 before the push).
- The **applications "all in one place"** claim is gone — the two stores do not sync, so
  it was false.
- The dashboard no longer says everything is unlocked while entitlements say otherwise.
- **"AI" is gone from the Swahili copy**, and page titles no longer sell the mechanism.

**The import path is honest.** A template that drops the photo now says so instead of the
user learning it from the exported PDF. The failures that returned a bare 500, or the
platform's raw `Request Entity Too Large`, or misdiagnosed a blank PDF as "a scan", now
name the actual condition.

**The match engine got real hygiene — deliberately, and the eval caught it.** Term
extraction now strips sentence punctuation from the *edges* of a term (`"salaam."` →
`"salaam"`) while keeping it *inside* one (`c++`, `c#`, `node.js`, `ci/cd`), and the advert
filler that reached users as keyword chips (`least`, `grow`, `various`, `ideally`…) is
filtered. Three golden pins moved (`frontend-engineer` 39→40, `sales-manager` 54→56,
`graduate-data-analyst` 55→54) — each carries its reason inline, and the *semantic*
invariants (`mustMatch`/`mustMiss`) all still pass, so the engine's meaning is intact.
This is the eval doing its job: it refused to let a scoring change through silently.

**Earlier in the night, already deployed:** `Karibu tena!` no longer greets a first-timer ·
SmartFit's magnification band narrowed from a 1.67× swing to 1.22× · the PDF face-squash
fixed · **the "CV too long" warning pill no longer prints onto a CV an employer receives** ·
a missing skill level no longer deletes the whole Skills section · the job-choice feature ·

deletes real matches (it was silently removing 58% of them).
