## 1. The single most important change

**Sumaiya's brain is ON.** For most of this session the product's AI was unconfigured —
`/api/ai/status` returned `{"configured":false,"provider":null}` — which cascaded through chat,
CV import, snap-to-apply and cover-letter generation. It now returns:

```
GET  /api/ai/status          → {"configured":true,"provider":"deepseek"}
POST /api/ai/assistant-turn  → {"success":true,"data":{"reply":"sawa"}}   HTTP 200 in 1.79s
```

Asked in Swahili for help writing a customer-service CV summary, it answered:

> "Nzuri, hiyo ni kazi nzuri. Niambie kwanza — unafanya kazi gani kwa sasa au ulifanya mara ya
> mwisho, na kwa kampuni gani?"

Swahili, **first person**, and it asks for what it needs instead of producing text.

## 2. Shipped tonight, by theme

### Correctness — things that lost or corrupted a user's data
| Fix | Why it mattered |
|---|---|
| A skill with a missing/malformed `level` **no longer deletes the entire Skills section** | 9 skills in → **0 out**; the section vanished from the CV *and* the PDF text layer, so the ATS score reported a document that was never delivered |
| An over-long CV no longer exports **with the editor's "⚠ CV too long" warning pill printed on it** | An employer was receiving a CV with an internal UI warning rasterised into it |
| A CV photo no longer exports **stretched** (a square face became an ellipse) | html2canvas ignores `object-fit`; now `background-size:cover`, with the accessible name preserved |
| `invented job listings` removed from public serving | 8 fabricated listings, one in Nairobi — same class as the fabricated testimonials removed earlier |
| The rejected-as-applied status fallback | An application that was rejected could render as *Applied* |

| Fix | Detail |
|---|---|
| `ichiujio` → **`vigezo`** in 7 screening-criteria strings | The owner's own decision; the one correct use ("clear filters") deliberately left alone |
| The "all in one place" claim dropped | The two applications stores do not sync, so the claim was false |
| A template that drops the photo now says so | Previously discovered only in the exported PDF |
| Import failures name the condition | Was *"she is busy"* for every failure |
| The memory screen speaks the reader's language | It showed raw English episode text to Swahili users **and fed those strings back into later conversations** |

  line was *"Sumaiya ana shughuli nyingi sasa hivi"* (third person, as if describing someone else)
  → *"Nina shughuli nyingi"*.

### Design — the two surfaces the owner approved
- **Chatbox redesign implemented on both surfaces** (`3380d07`), from the committed spec and

### Features

  listings (the owner's option A, leading) or supply your own advert or link, one tap away.
  Measured cost: opening the chooser **0 requests**; the listings call **4,849 bytes for 12 rows**
  versus **354,103 bytes** for the full feed; the user's-own branch **0 requests**.

### Access & safety
- **RLS on all tables** (108 owner-scoped policies); CV enumeration and anon job-column reads closed.
- **No fabricated testimonials** anywhere in production (verified by string count).
- **Production test data cleaned**: 0 throwaway accounts, the one real account untouched.

## 5. Release mechanics

```
version      : 1.6.25 / versionCode 10625   (apps/native/app.json + android/app/build.gradle)
JAVA_HOME    : C:\Users\hamis\tools\jdk-17.0.20.1+1
ANDROID_HOME : C:\Users\hamis\tools\android-sdk
build        : apps/native/android → ./gradlew assembleRelease --no-daemon
output       : apps/native/android/app/build/outputs/apk/release/app-release.apk
```

The APK currently on disk is the **old 1.6.24 artifact** (45,565,859 bytes, Sep 20 10:12). It must
be replaced by a build of the frozen tree, then verified: versionName, versionCode, the signing
key's subject, and a SHA-256 recorded in the APK ledger.

**Known recurring operational hazards, all of which cost time tonight:**
1. Six or more agents on one box drives it into memory pressure and produces **phantom timing
   failures** in the test suite. Serialise heavy work.
2. The tree is shared. A **bare `git commit`** swept one agent's six staged files into another
   agent's unrelated commit; a `git reset` was attempted and only a lock file stopped it. Always
   stage and commit **named paths**.
3. `adb` on this box is a native binary — pass `C:/...` paths, never `/c/...`.
